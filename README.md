# TrendCart 🛒

TrendCart is a full-stack e-commerce web application built using Node.js, Express.js, MongoDB, HTML, CSS, and JavaScript.

## Features

- User Registration & Login
- Product Listing
- Product Details Page
- Shopping Cart
- Order Processing
- Responsive Design

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Project Structure

```bash
TrendCart/
│
├── backend/
├── frontend/
├── .env
├── package.json
└── README.md
```

## Installation

```bash
npm install
npm run dev
```
